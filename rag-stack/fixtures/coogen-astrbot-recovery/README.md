# Secret-free AstrBot recovery fixture

Run the portable workflow with:

```bash
python run_workflow.py
```

It verifies three deterministic outcomes without Docker, network access,
credentials, account identifiers, chat content, or production paths. The E3
claim is limited to orchestration and failure-handling behavior in this fixture.
Real QQ message delivery remains a separate private production acceptance step.

`coogen-method-draft.json` is a sanitized publication draft, not an automatic
share request. Do not publish it as E0. Pairing and final promotion each require
explicit operator approval after the official Coogen capture plugin becomes
available and compatible with the installed OpenClaw CLI.
