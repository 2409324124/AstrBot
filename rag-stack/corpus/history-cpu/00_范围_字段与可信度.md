# 历史 CPU 型号与平台资料库：范围、字段与可信度

这套资料库服务于二手服务器、老工作站、家用实验室和本地 AI 主机的型号识别与平台比较。它与“AI Infra 硬件与推理工程知识库”分开维护：现代库解释当前硬件与推理方法，历史库保存旧型号、插槽、内存和 I/O 兼容性。AstrBot 可以在同一个会话中同时检索两套知识库。

## 首批覆盖范围

- Intel Xeon E5 与 E7 的 v1、v2、v3、v4 家族；
- 第一、第二、第三代 Intel Xeon Scalable，即 Skylake-SP、Cascade Lake-SP/Refresh、Ice Lake-SP；
- AMD Ryzen 3 与 Ryzen 5 中采用 Zen、Zen+、Zen 2 CPU 核心的桌面型号；
- AMD Ryzen Threadripper 1000、2000、3000 和 Threadripper PRO 3000WX；
- AMD EPYC 7001 Naples 与 EPYC 7002 Rome。

“老至强”不是严格产品名。本库不会把所有带 Xeon 品牌的 E3、D、W、Phi 和定制 OEM 型号混进同一张表。首批先覆盖常见双路/四路服务器与 E5 工作站平台；后续若增加 Xeon E3、W 或 D，将作为独立文档和独立审计计数。

## 每个 SKU 记录什么

型号表尽量保留这些字段：厂商、完整型号、产品族、代号/微架构、上市季度、核心/线程、基础与最高加速频率、末级缓存、TDP、socket、最大路数、内存类型/通道/最高速率、PCIe 代际/lanes 和官方来源。

平台级字段不能简单从单个 SKU 外推。例如，同属 EPYC 7002 的 P 后缀型号只支持单路，而非 P 型号通常可用于单路或双路；同属 Ryzen 3000 编号的 APU 也不必然采用 Zen 2 CPU 核心。因此型号归类以官方规格中的产品系列、核心架构和平台字段为准，不凭编号猜测。

## 可信度等级

1. A 级：Intel ARK、AMD Processor Specifications、官方 datasheet、product brief 或架构文档直接给出的规格。
2. B 级：厂商发布稿、官方技术博客或平台兼容列表，可用于发布时间、定位和历史说明。
3. C 级：主板厂商 CPU 支持列表、SPEC/OpenBenchmarking 等第三方结果，仅用于交叉核对或实测案例，必须明确标注。
4. 未能从一手资料确认的字段留空，不用聚合站数值补齐。

本库不记录没有测试条件的“性能百分比”。需要比较推理、编译或渲染速度时，应另存测试平台、内存条数与频率、NUMA、BIOS、操作系统、编译器、软件版本和功耗限制。

## 代际口径

AMD 官方 Zen 历史页将 Ryzen 1000 对应到 Zen、Ryzen 3000 对应到 Zen 2，并说明 Ryzen 2000 采用更新的 Zen+。但零售编号和核心架构不能在所有 APU/OEM 产品上机械等同，所以最终表仍以每个产品的官方规格为准。

Intel Xeon E5/E7 的 v1-v4 与 Xeon Scalable 的第一至第三代属于两套命名体系。本库保留原名，不把 E5 v4 写成“第四代 Xeon Scalable”。第一代 Xeon Scalable 的无代际前缀产品、第二代的 3200/4200/5200/6200/8200/9200、第三代的 4300/5300/6300/8300 等系列也分别建表。

## 数据维护与导入

`manifest.json` 是导入清单。只有清单中的 Markdown 会进入独立知识库；原始 HTML/PDF 缓存不上传。每次新增或更新必须先运行质量门，核对文件集合、来源链接、预期家族和 SKU 计数，再通过 AstrBot API 做增量或重建导入。旧知识库不删除，导入前先备份。
